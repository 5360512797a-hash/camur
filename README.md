# Çamur Cebi

Saha için çevrimdışı çalışan çamur uygulaması: test takibi, tavsiye, kimyasal stok, karışım hesapları, tank hacimleri, kuyu hacmi ve çamur tripi.

Dosyaların hepsini deponun ana klasörüne yükle, GitHub Pages'i aç, Safari'de adresi açıp "Ana Ekrana Ekle" de.
Güncelleme yaptığında `sw.js` içindeki `VERSION` değerini bir artır.
